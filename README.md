# PhainonDistributionCenter

> 刻法勒永志不忘。

ClassIsland 应用二进制文件分发系统。

下载量统计的配置、统计口径与验证方法见 [下载量统计部署说明](docs/download-statistics.md)。

pdcc 的 `Publish` 命令支持以下可选环境变量，均适用于文件仓库和子频道包上传：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PDC_MaxParallelism` | `16` | 最大并行上传数，必须为正整数。 |
| `PDC_MaxRetries` | `5` | 每个文件首次上传失败后的最大重试数，必须为非负整数；`0` 表示不重试。 |

可重试的上传错误按 1、2、4、8…秒的间隔重试，单次重试间隔最大为 256 秒。未设置环境变量时使用默认值，设置了非法值则终止发布并报告配置错误。
